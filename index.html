Problem & approach Why sorting matters in smart irrigation. 📍 Problem Sensors report soil-moisture (%) for every field. Water is limited, so the farmer must know which fields are driest without scanning the whole list each time. ⚡ Why Quick Sort It sorts in place with O(n log n) average time. It splits the fields around a pivot: drier ones go left, wetter ones right, then each side is solved the same way (divide & conquer). 🔁 Pipeline Each step of this model is one stage of the real system: Sensors → Quick Sort → Priority list → Greedy water allocation → Sprinklers 2.
